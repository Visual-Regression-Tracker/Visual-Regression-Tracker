# Statistics

The **Statistics** tab of a project shows **Results per build**: a bar for each build, split by status, so you can see how many runs passed, were approved, are unresolved and so on, and spot a build or a period where results got worse.

- Filter by **Branch**, or show **All branches**.
- The page says how many builds are kept, for example "4 builds kept (limit 100)". The limit is the project setting **Builds to keep**, see [Project settings](Project-settings): older builds are removed together with their runs.

With only a few builds the tab says so; trends appear after a few more.

Statuses are explained in [Statuses](Statuses).
